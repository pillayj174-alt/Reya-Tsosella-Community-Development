## Included media
The supplied organisation images have been added and optimised in `assets/`. The first image is used as the hero/background and a dedicated logo crop; the remaining images are presented in the community/about sections with controlled sizing and no overlap.

## Run locally
Open `index.html` in a browser. No build process is required.

## GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, `README.md`, and the `assets` folder.
3. In GitHub: Settings → Pages → Deploy from branch → select `main` and `/root`.
4. Save and wait for the Pages URL.

## Before launch
Replace placeholders with information approved by the NPO:
- Official logo
- Hero/community photographs
- Mission and vision
- NPO registration information
- Governance/office bearers
- Official programmes and projects
- Verified partners
- Jobs/opportunities
- News/events
- Donation details, only if the organisation confirms it accepts donations

## Backend roadmap
The front end is intentionally static and easy to expand. A later version can connect Supabase or another backend for:
- Admin authentication
- Job opportunity management
- News
- Events
- Projects
- Gallery
- Documents
- Contact enquiries
- Partner management

Do not publish unverified organisational claims.

## Donation safety
Do not publish or rely on banking details from social-media graphics without confirming them directly with authorised representatives of the organisation. Replace the donation placeholders only after verification.
